# Tanzania Travelers - Kilimanjaro Treks and Safaris

## Website Overview

Tanzania Travelers is a professional, responsive website for Kilimanjaro trekking and safari experiences. Built with modern web standards, this site showcases three popular Kilimanjaro routes with comprehensive information.

## Features

### 🏔️ Kilimanjaro Routes

1. **Lemosho Route**
   - 7-Day Option: $1,995 USD (95% success rate)
   - 8-Day Option: $2,295 USD (98% success rate)

2. **Machame Route**
   - 6-Day Option: $1,795 USD (85% success rate)
   - 7-Day Option: $2,095 USD (90% success rate)

3. **Marangu Route**
   - 5-Day Option: $1,495 USD (60% success rate)
   - 6-Day Option: $1,695 USD (85% success rate)

### 📋 Route Information

Each route includes:
- **Pricing**: Transparent cost breakdown
- **Quick Facts**: Duration, difficulty, success rates, group size
- **Day-by-Day Itinerary**: Detailed day-by-day schedule with elevations and distances
- **Inclusions & Exclusions**: Clear list of what's included and not included
- **Route FAQs**: Frequently asked questions and answers

To customize the website:

1. **Colors**: Edit the CSS variables in `styles.css`
2. **Content**: Modify HTML files directly
3. **Images**: Replace SVG logos with actual image files
4. **Routes**: Update pricing and itineraries as needed
